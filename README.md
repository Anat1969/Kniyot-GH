# קניות: היכן, מתי ומה

הסל שלך מול מחירי היום בכל הסניפים באשדוד, לפי קובצי שקיפות המחירים שהרשתות מפרסמות.

- **היכן:** מפת טבעות. גובה העמוד הוא מחיר הסל, הטבעת היא המרחק מהבית.
- **מתי:** ציר המבצעים על הסל, ומה נגמר השבוע.
- **מה:** אילו מוצרים מחזיקים את רוב הפער, והאם שווה לעצור בשני סניפים.

קלט: חיפוש מוצר, צילום קבלה, הדבקת רשימה או סריקת ברקוד.
פלט: סניף מומלץ, חיסכון נטו אחרי נסיעה, רשימת קניות וניווט.

```bash
npm install
```
```bash

```
